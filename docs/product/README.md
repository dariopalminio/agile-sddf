# Producto (`product/`)

**Propósito:** contexto del negocio — responde *¿por qué existe el producto?* Es la capa de vida
más larga (años) y su audiencia son el Product Owner y negocio.

**Convención de nombres:** tres documentos fijos, `vision.md`, `stakeholders.md` y
`objectives.md`; cualquier otro documento de contexto en kebab-case (`<tema>.md`).

**Regla:** aquí se describe el *por qué* y el *para quién*; el comportamiento que el producto debe
cumplir siempre va en `requirements/`, y el incremento que se construye ahora en `specs/`.
