# FR-024 — Modo incremental de actualización

## Descripción

Con el flag `--update`, el sistema SHALL re-analizar únicamente las secciones
marcadas `<!-- PENDING MANUAL REVIEW -->`, preservando verbatim las secciones ya completas.
