# FR-036 — Descomposición en tareas atómicas

## Descripción

El sistema SHALL producir `tasks.md` con tareas atómicas ordenadas por
dependencia (setup → componentes → soporte → verificación), cada una marcable como `- [ ]` /
`- [x]`.
