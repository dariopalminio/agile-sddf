# Dominios (`domains/`)

**Propósito:** modelo DDD del sistema — entidades, invariantes y lenguaje ubicuo. Es la capa de
vida más larga: cambia cuando cambia el negocio, no cuando cambia el código.

**Convención de nombres:** un documento por dominio, `domain-<nombre>.md` en kebab-case.

**Regla:** una regla de negocio vive en un solo lugar; desde requisitos e historias se enlaza,
no se copia.
