# Arquitectura (`architecture/`)

**Propósito:** estructura técnica del sistema — diagramas C4, stack y vistas de sistema. Vida
larga: se revisa cuando cambia la forma del sistema, no en cada historia.

**Convención de nombres:** `system-overview.md`, `tech-stack.md` y documentos temáticos en
kebab-case; los diagramas C4 en `c4/`.

**Regla:** una decisión que restringe el futuro no se documenta aquí, se registra como ADR en
`adr/` y desde aquí se enlaza.
