# Decisiones de arquitectura (`adr/`)

**Propósito:** decisiones transversales inmutables (`ADR-NNNN`). Un ADR es obligatorio cuando la
decisión afecta a más de un módulo o restringe decisiones futuras.

**Convención de nombres:** `ADR-NNNN-<slug>.md`, numeración secuencial de cuatro dígitos, a partir
de la plantilla `templates/adr-template.md`.

**Regla:** un ADR aceptado no se edita; se reemplaza con uno nuevo que declara `supersedes` y el
antiguo recibe `superseded-by`.
