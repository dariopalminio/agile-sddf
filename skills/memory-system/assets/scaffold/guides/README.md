# Guías (`guides/`)

**Propósito:** explicaciones didácticas y how-tos que ayudan a entender y usar el sistema. Vida
media: se actualizan cuando cambia la forma de trabajar.

**Convención de nombres:** `guide-<tema>.md` para explicaciones y `how-to-<tema>.md` para
procedimientos paso a paso, en kebab-case.

**Regla:** una guía explica; no fija reglas (eso es una policy) ni describe operación en
producción (eso es un runbook).
