# Runbooks (`runbooks/`)

**Propósito:** procedimientos operativos — despliegue, recuperación, incidentes, tareas de
mantenimiento. Vida larga.

**Convención de nombres:** `runbook-<tema>.md` en kebab-case, un procedimiento por archivo, con
precondiciones, pasos numerados y verificación final.

**Regla:** un runbook debe poder ejecutarse sin contexto adicional; si necesita explicación de
fondo, enlaza a la guía correspondiente.
