# Policies (`policies/`)

**Propósito:** reglas de gobernanza que desarrollan los principios de `constitution.md` (que vive
en la raíz de la memoria, un nivel por encima). Vida larga.

**Convención de nombres:** `<nombre>-policy.md` en kebab-case. Toda policy declara de qué
principio deriva (`derives-from: constitution`).

**Regla:** ante conflicto entre una policy y la constitución, prevalece la constitución.
